# Community code of conduct

Be respectful, patient, and specific. Help people understand risks before asking them to run commands on a device.

The project does not accept harassment, discrimination, credential sharing, piracy, unauthorized network access, DRM bypass, or instructions aimed at devices the operator does not own or administer.

Privacy is part of respectful participation: redact serial numbers, addresses, SSIDs, IPs, account names, tokens, and personal recommendations from screenshots and logs.

Maintainers may edit or remove unsafe material and restrict participation when necessary to protect users or the project.
