# Security policy

Do not report device credentials, ADB keys, authentication tokens, certificate material, serial numbers, or remotely exploitable details in a public issue.

For a suspected vulnerability in this guide, prepare a minimal report containing:

- The affected file and revision.
- Impact on an owned JHSD200 device.
- A redacted reproduction that excludes identifiers and credentials.
- A safe remediation or rollback when known.

Report vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature. If that feature is unavailable, do not publish secrets; open a short issue asking for a private contact channel.

Upstream CleanYourTV issues belong to its own security process. Vulnerabilities in Jio services, firmware, or infrastructure should be disclosed to the relevant vendor through an authorized channel.
